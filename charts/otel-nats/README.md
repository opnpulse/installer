# OTel NATS

[OTel NATS by AppsCode](https://github.com/opnpulse/otel-nats) - NATS JetStream buffer between workload clusters and the telemetry backends

## TL;DR;

```bash
$ helm repo add appscode-charts oci://ghcr.io/appscode-charts
$ helm repo update
$ helm search repo appscode-charts/otel-nats --version=v2026.9.22
$ helm upgrade -i otel-nats appscode-charts/otel-nats -n monitoring --create-namespace --version=v2026.9.22
```

## Introduction

This chart deploys an OTel NATS pipeline on a [Kubernetes](http://kubernetes.io) cluster using the [Helm](https://helm.sh) package manager.

## Prerequisites

- Kubernetes 1.21+
- cert-manager, for the NATS server and forwarder client certificates
- prom-label-proxy, which is what this chart writes through

## Installing the Chart

To install/upgrade the chart with the release name `otel-nats`:

```bash
$ helm upgrade -i otel-nats appscode-charts/otel-nats -n monitoring --create-namespace --version=v2026.9.22
```

The command deploys an OTel NATS pipeline on the Kubernetes cluster in the default configuration. The [configuration](#configuration) section lists the parameters that can be configured during installation.

> **Tip**: List all releases using `helm list`

## Uninstalling the Chart

To uninstall the `otel-nats`:

```bash
$ helm uninstall otel-nats -n monitoring
```

The command removes all the Kubernetes components associated with the chart and deletes the release.

Specify each parameter using the `--set key=value[,key=value]` argument to `helm upgrade -i`. For example:

```bash
$ helm upgrade -i otel-nats appscode-charts/otel-nats -n monitoring --create-namespace --version=v2026.9.22 --set image.repository=ghcr.io/opnpulse/opentelemetry-collector-ace
```

Alternatively, a YAML file that specifies the values for the parameters can be provided while
installing the chart. For example:

```bash
$ helm upgrade -i otel-nats appscode-charts/otel-nats -n monitoring --create-namespace --version=v2026.9.22 --values values.yaml
```
